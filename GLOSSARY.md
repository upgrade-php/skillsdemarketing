# Glossário (pt-BR ↔ en)

Termos de marketing usados nas skills, com a tradução padronizada adotada no fork.
Consulte antes de adaptar uma nova skill, para manter consistência terminológica
entre as 50 skills (FR-013).

| Termo (en) | Tradução (pt-BR) | Notas de uso |
|---|---|---|
| CRO (conversion rate optimization) | CRO / otimização de conversão | Sigla mantida em inglês (uso corrente no mercado brasileiro); expandida como "otimização de conversão" na primeira menção de cada skill. |
| ICP (ideal customer profile) | ICP / perfil de cliente ideal | Sigla mantida; expandida no primeiro uso. |
| MQL / SQL | MQL / SQL | Siglas mantidas sem tradução — termo técnico de RevOps de uso corrente em pt-BR. |
| funnel | funil | Traduzido sempre — "funil de marketing", "funil de conversão", "funil de vendas". |
| churn | churn | Mantido em inglês — termo consagrado no mercado SaaS brasileiro; "churn de cliente", "taxa de churn". |
| onboarding | onboarding | Mantido em inglês — sem tradução natural equivalente em uso corrente. |
| lead | lead | Mantido em inglês — "gerar lead", "lead qualificado". |
| stakeholder | stakeholder | Mantido em inglês. |
| workflow | workflow / fluxo de trabalho | "Workflow" quando técnico/de automação; "fluxo de trabalho" em contexto mais narrativo. |
| hook (copy/vídeo) | gancho | Traduzido — "gancho" é o termo de uso corrente em copywriting e vídeo em pt-BR. |
| growth loop | loop de crescimento | Traduzido, mantendo "loop" como substantivo emprestado já consagrado. |
| A/B test | teste A/B | Traduzido — forma padrão em pt-BR. |
| benchmark | benchmark | Mantido em inglês. |
| pipeline (vendas) | pipeline | Mantido em inglês — "pipeline de vendas". |
| deal (negociação) | negócio | Traduzido — "negócio fechado", "tamanho do negócio". |
| revenue | receita | Sempre traduzido. |
| engagement | engajamento | Sempre traduzido. |
| activation (produto) | ativação | Sempre traduzido — "momento de ativação", "taxa de ativação". |
| aha moment | momento aha | Traduzido parcialmente — "aha" mantido como termo emprestado consagrado em produto/growth. |
| feature (produto) | funcionalidade | Sempre traduzido — nunca "feature" solto. |
| freemium | freemium | Mantido em inglês. |
| paywall | paywall | Mantido em inglês — sem equivalente natural em pt-BR. |
| upsell / cross-sell | upsell / cross-sell | Mantidos em inglês — termos técnicos de uso corrente. |
| CAC (customer acquisition cost) | CAC / custo de aquisição de cliente | Sigla mantida; expandida no primeiro uso. |
| LTV (lifetime value) | LTV / valor vitalício do cliente | Sigla mantida; expandida no primeiro uso. |
| ROI | ROI / retorno sobre investimento | Sigla mantida; expandida no primeiro uso. |
| brainstorm | brainstorm | Mantido em inglês. |
| B2B / B2C / DTC | B2B / B2C / DTC | Siglas mantidas — uso corrente. |
| copy (texto persuasivo) | copy | Mantido em inglês como substantivo — "escrever a copy", nunca "cópia". |
| landing page | landing page | Mantido em inglês. |
| CTA (call to action) | CTA / chamada para ação | Sigla mantida; expandida no primeiro uso quando relevante. |
| SLA | SLA / acordo de nível de serviço | Sigla mantida; expandida no primeiro uso. |
| dark pattern | dark pattern | Mantido em inglês — termo técnico de UX sem tradução corrente estabelecida. |
| Product-led growth (PLG) | PLG / crescimento liderado por produto | Sigla mantida; expandida no primeiro uso. |
| sales-led | sales-led / liderado por vendas | Ambas as formas aparecem, conforme o contexto da skill. |
| win-back | win-back / reconquista | "Reconquista" preferido em título de seção; "win-back" mantido quando nomeando o fluxo técnico. |
| opt-in / opt-out | opt-in / opt-out | Mantidos em inglês — termos técnicos de e-mail/SMS marketing e LGPD de uso corrente. |
| segment / segmentation | segmento / segmentação | Sempre traduzido. |
| retainer (agência) | retainer | Mantido em inglês — termo de mercado de serviços/agências. |
| deck (apresentação) | deck | Mantido em inglês — "deck de vendas", "pitch deck". |
| playbook | playbook | Mantido em inglês. |
| teardown (análise) | teardown | Mantido em inglês — "teardown de página de preço". |
